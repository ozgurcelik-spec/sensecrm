# Milestone 8C — Dosya ekleri (nesne depolama): `Files` modülü, MinIO/S3 depolama portu, kayıt ekleri, kota, yaşam döngüsü (plan + HTTP kontratı)

PRD: [zoho-crm-klonu.prd.md](../../.claude/prds/zoho-crm-klonu.prd.md) · Kararlar: [kararlar.md](../architecture/kararlar.md) (K11, K13, K14, K16, K17, K18) · Mimari: [mimari.webp](../architecture/mimari.webp) katman 5 "Nesne Depolama (Dosyalar/Ekler)" · Önceki: [M6A](m6a-ticaret.md), [M6B](m6b-servis.md), [M6C](m6c-pazarlama.md), [M7](m7-saas-hazirlik.md) (limitler, KVKK imhası), güvenlik: [hardening-report.md](../security/hardening-report.md), işletim: [runbook.md](../operations/runbook.md) · Pano kartı: `C-M8C` (dal `m8/files`). Biçim kuralları M2–M7 ile aynı: taban yol `/api/v1`, JSON camelCase, enum'lar camelCase string, `null` alanlar yazılmaz, hatalar ProblemDetails + `code` (+ `args`, doğrulamada `errors`), sayfalı liste `{ items, page, pageSize, totalCount }` (`page` 1'den, `pageSize` varsayılan 25 / en çok 100), `sort` = `alan` veya `-alan` (bilinmeyen alan yok sayılır, her zaman kimlikle kararlı), `q` = `ILIKE` + kaçışlı parametre, zaman damgaları ISO 8601 UTC. Kiracı token'dan gelir; başka kiracının kaydı/dosyası her zaman `not_found` (404).

**Çıktı:** Kullanıcı bir kayıt (firma, kişi, potansiyel müşteri, fırsat, aktivite, talep, teklif, sipariş, kampanya) detayında "Ekler" sekmesinden dosya sürükleyip bırakır; dosya API üzerinden **akış halinde** doğrulanır (uzantı + içerik imzası + boyut + kota + isteğe bağlı tarayıcı), kiracı önekli tek bir S3 uyumlu (MinIO) kovaya yazılır; listeden indirilir, adı değiştirilir, silinir, görsel/PDF önizlenir. Erişim kararı her istekte **kaydın kendi izniyle** verilir (indirme = kaydı okuyabilme, yükleme/silme/yeniden adlandırma = kaydı yazabilme). Depolama kotası M7 plan limitlerine `maxStorageMb` olarak eklenir. Kiracı imhası (KVKK) nesneleri de siler ve doğrular. **Sürümleme, paylaşım bağlantısı, OCR/tam metin arama, ofis belgesi önizleme, virüs tarama uygulaması yoktur** (kapsam dışı).

## Depolama

### Port ve nesne anahtarı
```csharp
public readonly record struct ObjectKey   // TEK oluşturma yolu: For(tenantId, year, fileId); Parse(string) katı regex + Guid doğrulaması
{ Guid TenantId; int Year; Guid FileId; override string ToString(); /* "{tenantId:D}/{yyyy}/{fileId:N}" */ static string TenantPrefix(Guid tenantId); /* "{tenantId:D}/" */ }

public interface IFileStorage
{
    Task PutAsync(ObjectKey key, Stream content, long length, CancellationToken ct);        // content aranabilir (seekable), length kesin
    Task<StoredObject?> GetAsync(ObjectKey key, ByteRange? range, CancellationToken ct);    // yoksa null; StoredObject: Stream, Length, RangeStart/End, IAsyncDisposable
    Task<ObjectStat?> StatAsync(ObjectKey key, CancellationToken ct);                       // (size, lastModified); yoksa null
    Task<bool> DeleteAsync(ObjectKey key, CancellationToken ct);                            // idempotent
    Task<long> DeletePrefixAsync(Guid tenantId, CancellationToken ct);                      // kiracının TÜM nesneleri (imha); listeleme + 1000'lik toplu silme
    IAsyncEnumerable<ObjectInfo> ListAsync(Guid tenantId, CancellationToken ct);            // "{tenantId:D}/" öneki; sayfalı (1000)
    Task<StorageHealth> CheckAsync(CancellationToken ct);                                    // erişilebilirlik + kova var + varsayılan şifreleme
}
```
- **Kiracı koruması (derinlemesine savunma):** her adaptör metodu `ObjectKey.TenantId == ITenantContext.TenantId` denetler; uyuşmazlık = `InvalidOperationException` + güvenlik günlüğü (kimlik/anahtar **hash'i**, dosya adı yok). Worker işleri ve imha, çağırmadan önce `ITenantContextSetter.BeginScope(tenantId)` kurar. Veritabanından okunan `storage_key` her kullanımdan önce `ObjectKey.Parse` ile yeniden doğrulanır ve kiracıyla karşılaştırılır (kurcalanmış satır başka kiracının nesnesini okutamaz).
- **Anahtar düzeni:** tek kova (`Files:Storage:Bucket` = `crm-files`), nesne anahtarı **`{tenantId:D}/{yyyy}/{fileId:N}`** (`yyyy` = yükleme yılı UTC, `fileId` = sunucunun ürettiği `Guid.CreateVersion7()`). Kullanıcıdan gelen **hiçbir** parça (dosya adı, tür, kayıt kimliği) anahtara girmez. Nesne meta verisinde dosya adı/`Content-Disposition` **saklanmaz** (kişisel veri ve başlık enjeksiyonu yok); depoda `Content-Type` her zaman `application/octet-stream`, sunulan tür veritabanındaki kanonik türden gelir. Kiracı başına kova **yok** (1.000 kiracıda kova/IAM çoğalması; yalıtım uygulama + tek kovaya kısıtlı servis hesabı ile).
- **Anahtar yanlışı yok:** kiracı öneki tam GUID (`senseik` gibi 12 karaktere **kısaltılmaz**; çakışma olamaz).

### SDK seçimi: `AWSSDK.S3` (Minio .NET SDK değil)
K11 "S3 uyumlu" der, MinIO'yu değil: sunucu değişebilmeli. (1) MinIO topluluk sürümünün 2025 sonundan itibaren bakım moduna geçtiği ve hazır imaj dağıtımını bıraktığı bildirildi (DevOps imaj kaynağını/sürümünü/lisansı **doğrulamalıdır**, Açık işler); S3-genel istemci sayesinde sunucu (MinIO/SeaweedFS/Garage/Ceph RGW) **kod değişmeden** değişir. (2) `Minio` .NET SDK'da indirme geri çağırma tabanlıdır (`WithCallbackStream`); HTTP yanıtına doğrudan akıtmak için ara tampon/boru gerekir. `AWSSDK.S3` `GetObjectResponse.ResponseStream` ve `ByteRange` verir → gerçek akış + aralıklı indirme. (3) Yaygın kullanım ve bakım. **Bedel/önlemler:** daha büyük bağımlılık; SDK v4 varsayılan `aws-chunked`/CRC32 sağlama toplamı bazı S3 uyumlu sunucularla sorun çıkarabildiği için `RequestChecksumCalculation = WHEN_REQUIRED`, `ResponseChecksumValidation = WHEN_REQUIRED`, `ForcePathStyle = true`; iç ağ düz HTTP olduğundan SDK yükün SHA-256'sını hesaplar → **aranabilir akış** gerekir (bu yüzden yükleme geçici dosyadan yapılır, aşağıda). `senseik`'ten yalnız fikirler alınır (`IFileStorage` sınırı, `UploadFilePolicy` uzantı+tür allow-list ve ad temizleme fikri, kota değer nesnesi); HR'a özgü mantık, presigned akış ve **12 karaktere kısaltılmış kiracı kova adı kopyalanmaz**. Paket sürümü `Directory.Packages.props`'ta sabitlenir (4.x kararlı), test için `Testcontainers.Minio`.

### Şifreleme (at rest)
`Files:Storage:Encryption` = `required` (Production varsayılanı) | `none` (yalnız Development/Testing; Production'da `none` başlatmaz — istisna için `Files:Storage:AcknowledgeUnencrypted=true` ile işletme "disk şifreli" beyanı verir, günlüğe uyarı). `required` iken: (a) MinIO **statik KMS anahtarı** ile açılır (`MINIO_KMS_SECRET_KEY_FILE` → Docker secret `minio_kms_key`, biçim `crm-files-key:<base64 32 bayt>`; dış KES/ağ çağrısı yok, K17 korunur); (b) `minio-init` kovada **varsayılan SSE-S3** ayarlar (uygulama SSE başlığı göndermez, TLS bağımlılığı yok); (c) `CheckAsync` `GetBucketEncryption` ile doğrular — yoksa sağlık `Unhealthy` ve **yüklemeler reddedilir** (`file.storage_unavailable`, sessizce şifresiz yazılmaz). **KMS anahtarı yedeklenmeden veri yedeği anlamsızdır** (runbook §4/§6).

### Compose ve sırlar
- **Üretim (`deploy/docker-compose.prod.yml`, DevOps):** `minio` servisi **yalnız `backend` (internal) ağında**, **`ports` yok** (asla yayınlanmaz), `restart: unless-stopped`, sabit sürüm etiketi (digest önerilir; `latest` yok), `MINIO_BROWSER=off` (konsol kapalı; yönetim `docker compose exec`/`mc` ile), `volumes: miniodata:/data`, kaynak sınırı (`MINIO_MEM_LIMIT`, varsayılan 1g), healthcheck `mc ready local` (imajda yoksa curl `/minio/health/live`; DevOps doğrular). Kök kimlik bilgileri **Docker secret dosyaları**: `MINIO_ROOT_USER_FILE=/run/secrets/minio_root_user`, `MINIO_ROOT_PASSWORD_FILE=/run/secrets/minio_root_password`, `MINIO_KMS_SECRET_KEY_FILE=/run/secrets/minio_kms_key`. Tek seferlik **`minio-init`** (mc imajı, `restart: "no"`): kovayı oluşturur (yoksa), varsayılan SSE-S3, **yalnız bu kovaya** izinli politika ve `crm-files` **servis hesabı** (erişim/gizli anahtar secret dosyalarından: `minio_app_access_key`, `minio_app_secret_key`); idempotent, her `up`'ta koşar. `api`, `worker` ve `migrator` (imha yeniden oynatması) `minio-init: service_completed_successfully`'a bağlanır; uygulama kimlik bilgileri **secret dosyaları** olarak `Files__Storage__AccessKey`/`Files__Storage__SecretKey` adıyla bağlanır (`/run/secrets/<Ad>` → `Files:Storage:…` deseni, M5). Uygulamada kök kimlik bilgisi **yoktur**; uygulama hesabı kova oluşturamaz/silemez, yönetim API'sine erişemez. `.env`: `MINIO_IMAGE`, `MINIO_MEM_LIMIT`; `generate-secrets.{sh,ps1}` yeni sırları üretir (varsayılan parola yok). `api` için `tmpfs: /tmp` (512 MB; yükleme geçici dosyaları).
- **Geliştirme (`infra/docker-compose.yml`):** `minio` (+ `minio-init`) `127.0.0.1:${MINIO_PORT:-19000}:9000` ve konsol `19001` (standart+10000 kuralı, yalnız yerel), yalnız yerel geliştirme kimlik bilgileri (dosyada "yalnız yerel" notu), şifreleme yok (`Encryption=none` Development varsayılanı). Docker'sız geliştirme: `Files:Storage:Provider=filesystem` (`RootPath`).
- Web `nginx` (`web/nginx/default.conf.template` + `security-headers.conf`, DevOps): (1) `location = /api/v1/files` (yükleme) için `client_max_body_size` = `Files:Upload:MaxRequestMb`+ 5 (varsayılan 115m), `proxy_request_buffering off`, `proxy_read_timeout/proxy_send_timeout 300s`; (2) `location ~ ^/api/v1/files/[0-9a-fA-F-]{36}/content$` için `proxy_buffering off`, 300 sn zaman aşımı (akış); ikisi de mevcut `/api/` bloğundaki `add_header` deseniyle (yalnız HSTS, diğer başlıkları API koyar). Genel `client_max_body_size 20m` **değişmez** (M2 Kestrel 1 MB sınırı da genel kalır). (3) CSP'ye önizleme için **yalnız** `img-src 'self' data: blob:` ve `frame-src 'self' blob:` eklenir (`object-src 'none'`, `script-src 'self'` aynen; smoke/CSP testleri güncellenir).

| `modified_date` | `Entity<T>` tabanından (yeniden adlandırma) |

İndeksler (kiracı önce): `(tenant_id, record_type, record_id, uploaded_at DESC) WHERE state <> 'deleted'` (kayıt listesi); `UNIQUE (storage_key)` (önek kiracıdır); `(tenant_id) INCLUDE (size_bytes) WHERE state IN ('ready','quarantined','missing')` (kota/kullanım: yalnız indeks taraması); `(tenant_id, deleted_at) WHERE state = 'deleted'` (temizlik); `(tenant_id, record_missing_since) WHERE record_missing_since IS NOT NULL`.

**Kotaya sayılan:** `ready`, `quarantined`, `missing` (nesne var sayılır); `deleted` sayılmaz. `IAuditLogged`: yükleme/yeniden adlandırma/silme K14 kapsamında `audit.audit_log_entries`'e yazılır (`FilesAuditEntities.File = "file"`; alan adı `name` dahil — kiracı içi iş verisi, imhada `audit` adımıyla silinir; `sha256`/`storage_key` yazılmaz).

### `files.file_access_log` (`FileAccessLogEntry`, `ITenantEntity`, append-only, `IAuditLogged` **değil**)
`id`, `tenant_id`, `occurred_at`, `file_id`, `user_id`, `action` (`download` \| `preview`). **IP, ad, içerik yok** (veri minimizasyonu). Aralıklı isteklerde yalnız **ilk** parça (Range yok veya `bytes=0-`) kaydedilir (bir indirme = bir satır). İndeksler: `(tenant_id, occurred_at DESC)`, `(tenant_id, file_id, occurred_at DESC)`. Saklama `Files:AccessLog:RetentionDays` (365; temizlik purge işinde). Okuma arayüzü kapsam dışı (runbook'ta SQL); amaç "kim neyi indirdi" izi.

### Diğer
Modülün `outbox_messages`/`inbox_messages` tabloları (`AddModuleDbContext`). Kota/kullanım tablosu **yoktur** (kısmi indeksle `SUM` yeter; YAGNI). Migration sahibi Files (`InitialFiles`); **Platform şemasında migration yoktur** (`limits`/`overrides` jsonb'dir), başka modülün şeması değişmez.

## Yükleme akışı (`POST /files?recordType&recordId`, multipart)

Yükleme **iki fazlıdır**; DB işlemi istemci hızına bağlanmaz:
1. **Faz 0 — erken red (gövde okunmadan):** dispatcher'dan `AuthorizeUploadCommand` (`ICommand`, `[AnyAuthenticatedUser]`, `IAttachmentAccess` yazma denetimi) → izin/plan/varlık/`tenant.suspended`/kapı modülü hataları **hiçbir bayt okunmadan** döner. `Content-Length` varsa ve `Files:Upload:MaxRequestMb`'yi aşıyorsa `413 file.too_large` (gövde okunmaz). Kestrel gövde sınırı yalnız bu uçta `IHttpMaxRequestBodySizeFeature` ile `MaxRequestMb`'ye çıkarılır (genel 1 MB sınırı korunur); model bağlama yok, `MultipartReader` ile elle okuma (`[DisableFormValueModelBinding]`).
2. **Faz 1 — hazırlama (`IUploadStager`, işlem yok), parça parça, sırayla:** `file` adlı her parça için: (a) ad temizleme + uzantı allow-list denetimi (bayt okumadan); (b) akışı **geçici dosyaya** kopyala (`FileOptions.DeleteOnClose`; dizin `Files:Upload:TempDirectory`, üretimde `tmpfs`) — **aynı geçişte** bayt say (sınır `MaxFileMb` aşılınca hemen kes: `413 file.too_large`, `Content-Length` yokken/chunked'da da) ve **SHA-256** hesapla; (c) 0 bayt → `file.empty`; (d) **içerik imzası** (`FileTypeCatalog`); (e) `IFileScanner` (sıralama: imza → tarama; tarama yalnız imzayı geçen dosyada). Sonuç `IStagedUpload` (ad, uzantı, kanonik tür, bayt, sha256, tarama sonucu, `OpenRead()`). Aynı istekte dosyalar **sırayla** işlenir → istek başına en çok bir geçici dosya (tmpfs boyutu = eşzamanlı istek × `MaxFileMb`).
3. **Faz 2 — işleme (`AttachFileCommand`, UoW işlemi açık; `[AnyAuthenticatedUser]` + `[NoPlanLimit("Dosya eki kayıt sayısına değil depolama kotasına sayılır; kota handler'da ILimitGuard ile zorlanır")]`):** (i) `IAttachmentAccess` yeniden; (ii) **kota:** `ILimitGuard.EnsureAsync(new LimitDemand(LimitKeys.Storage, "files", Delta: sizeBytes))` — Platform tarafı `pg_advisory_xact_lock(hashtextextended('limit:storage:'||tenantId, 0))`'ı **Files UoW'sunda** alır, sonra `files.storage_bytes`'ı (kesin `SUM`, önbelleksiz) okur; `used + delta > maxBytes` → `402` (handler `plan.limit_exceeded`/`storage` sonucunu `file.quota_exceeded`'a çevirir: `args.maxBytes`, `args.usedBytes`, `args.requestedBytes`); (iii) `IFileStorage.PutAsync` (≤ `MaxFileMb`, iç ağda tek PUT; kilit yalnız bu süre tutulur); (iv) satır ekle (`state = ready` veya karantina), `FileAttached` outbox olayı; (v) işlem `commit`. **Hata yolları:** PUT hatası → işlem geri alınır, `503 file.storage_unavailable`, satır yok; PUT sonrası commit hatası → handler `DeleteAsync` ile telafi eder, başarısızsa nesne yetim kalır (uzlaştırma siler). Geçici dosya her yolda (başarı/hata/iptal) silinir.
4. **Çoklu dosya semantiği:** her `file` parçası **bağımsız** işlenir (kendi UoW'si); en çok `Files:Upload:MaxFilesPerRequest` (10) parça (fazlası `file.too_many_files`). Yanıt: hepsi başarılı → **201**; bazıları başarısız → **200** `{ items, failed }`; hiçbiri başarılı değil → **ilk hatanın** ProblemDetails'i (tek dosyalı normal durumda standart hata). `failed[]` öğesi `{ fileName, code, args? }` (`fileName` temizlenmiş; günlüğe yazılmaz). Web tek dosyayı istek başına gönderir (dosya başına ilerleme/hata); çoklu parça API kolaylığıdır.
5. **İstek sınırları:** `Files:Upload:MaxFileMb` (25, doğrulama 1–200), `MaxRequestMb` (`MaxFileMb × MaxFilesPerRequest` üst sınırı, varsayılan 110), eşzamanlı yükleme kiracı başına `Files:RateLimiting:ConcurrentUploadsPerTenant` (4) ve genel `MaxConcurrentUploads` (16) → `429 general.rate_limit_exceeded`; hız sınırı politikası `files-upload` (kullanıcı `sub` başına dakikada 30 parça; her parça bir jeton), indirme `files-download` (120/dk). Genel kullanıcı/kiracı sınırlayıcıları (600/3000) ayrıca geçerlidir.

## Güvenlik kuralları

### Dosya adı (`FileNamePolicy`, saf)
Sırayla: NFC normalizasyonu → son `/` veya `\` sonrası (dizin yolu atılır) → **kontrol karakterleri (Cc), biçim/çift yönlü karakterler (Cf: U+200B–200F, U+202A–202E, U+2066–2069, U+FEFF) ve `< > : " | ? *` çıkarılır** → `..` dizileri tek noktaya indirilir → baş/son boşluk ve nokta kırpılır → Windows ayrılmış aygıt adları (`CON, PRN, AUX, NUL, COM1–9, LPT1–9`, uzantısız kısım) başına `_` alır → uzunluk 200 UTF-16 birim (uzantı korunur, gövde kısaltılır) → boş kalırsa `400 file.name_invalid`. Uzantı = temizlenmiş adın **son** uzantısı (küçük harf). **Çift uzantı:** son uzantıdan önceki herhangi bir parça tehlikeli listedeyse (`exe, com, bat, cmd, scr, msi, jar, js, vbs, ps1, html, htm, svg, hta, lnk`) `file.type_not_allowed` (`a.exe.pdf` reddedilir). Ad **yalnız** veritabanında ve `Content-Disposition`'da yaşar; nesne anahtarına/dosya sistemi yoluna hiçbir zaman girmez (dosya sistemi adaptörü de yalnız `ObjectKey` ile yol kurar, kök dışına çıkışı `Path.GetFullPath` önek denetimiyle reddeder).

### Tür allow-list ve içerik imzası (`FileTypeCatalog`, kodda; yapılandırma yalnız **daraltabilir**)
`Files:Upload:AllowedExtensions` varsayılanı = katalogun tamamı; katalogda olmayan uzantı yapılandırması açılışta reddedilir (yapılandırma yeni tür **ekleyemez**, çünkü her tür bir imza denetçisi ister).

| Uzantı(lar) | Kanonik tür | İmza denetimi | Önizleme |
|---|---|---|---|
| `pdf` | `application/pdf` | `%PDF-` ilk 1024 baytta | evet |
| `jpg`, `jpeg` | `image/jpeg` | `FF D8 FF` | evet |
| `png` | `image/png` | 8 baytlık PNG imzası | evet |
| `gif` | `image/gif` | `GIF87a`/`GIF89a` | evet |
| `webp` | `image/webp` | `RIFF????WEBP` | evet |
| `docx`, `xlsx`, `pptx` | OOXML türleri | ZIP (`PK\x03\x04`) + merkezi dizinde `[Content_Types].xml` ve `word/`, `xl/` veya `ppt/` girişi; **`vbaProject.bin` veya `.exe/.dll` girişi varsa reddedilir** (makro/yürütülebilir taşıyan dosya) | hayır |
| `odt`, `ods` | OpenDocument | ZIP + ilk giriş `mimetype` (sıkıştırmasız, beklenen dize) | hayır |
| `doc`, `xls`, `ppt` | Office 97 | OLE2 imzası `D0 CF 11 E0 A1 B1 1A E1` | hayır |
| `txt` | `text/plain; charset=utf-8` | ilk 8 KB geçerli UTF-8, NUL yok, `\t\r\n` dışı kontrol karakteri yok, HTML/SVG/script ile başlamıyor | hayır |
| `csv` | `text/csv; charset=utf-8` | `txt` ile aynı | hayır |

ZIP incelemesi yalnız **merkezi dizini** okur (giriş adı listesi; içerik açılmaz, giriş sayısı ≤ 20 000 → zip bombası/CPU yok). **Karar:** (1) uzantı allow-list'te değilse `415 file.type_not_allowed`; (2) imza, uzantının ailesiyle uyuşmuyorsa (ör. `.pdf` adlı EXE, `.png` içinde JPEG) `422 file.content_mismatch`; (3) istemcinin `Content-Type` beyanı **yalnız danışmandır**: katalogda **başka** bir aileye eşleniyorsa (ör. `text/html` veya `image/svg+xml` beyanı) `file.content_mismatch`, bilinmeyen/`application/octet-stream` yok sayılır; (4) saklanan/sunulan tür **her zaman** kanonik türdür. Varsayılan olarak `svg, html, htm, js, exe, zip, rar, 7z, eml, msg, heic, mp4` izinli değildir (kapsam dışı listesi).

### Sunum başlıkları (indirme/önizleme)
`Content-Type` = kanonik tür; `X-Content-Type-Options: nosniff` (zaten global); `Content-Disposition: attachment; filename="<ASCII yedek>"; filename*=UTF-8''<yüzde kodlu>` (ASP.NET `ContentDispositionHeaderValue`; ASCII yedekte `"`, `\`, CR/LF ve ASCII dışı `_` olur → başlık enjeksiyonu yok); `Cache-Control: private, no-store`; `Accept-Ranges: bytes`; `ETag: "<sha256>"` + `If-None-Match` → 304; `Cross-Origin-Resource-Policy: same-origin`. **Satır içi önizleme** yalnız `?disposition=inline` ve **yalnız önizlenebilir türler** (png, jpeg, gif, webp, pdf; aksi `400 validation` `errors.disposition`): `Content-Disposition: inline; …`, `X-Frame-Options: SAMEORIGIN` (SecurityHeaders `TryAdd` olduğundan açıkça koyulan kazanır), CSP: görseller `default-src 'none'; img-src 'self'; style-src 'unsafe-inline'; frame-ancestors 'self'; sandbox`, PDF `default-src 'none'; frame-ancestors 'self'` (Chrome PDF görüntüleyicisi `sandbox` ile çalışmaz). `txt/csv/Office` **asla** satır içi sunulmaz. Web, gövdeyi `Authorization` başlıklı istekle **blob** olarak alır (token çerezde değil); blob `Blob.type` sunucu başlığından **ve** yalnız önizleme allow-list'inden verilir (istemci tarafı ikinci kilit).

### Aralıklı indirme
`Range: bytes=a-b` (tek aralık) → `206`, `Content-Range`, `Content-Length`; geçersiz/sığmayan aralık `416` (`Content-Range: bytes */len`); birden çok aralık → tam gövde `200` (RFC 7233'e uygun). Aralık `IFileStorage.GetAsync(range)` ile depodan (SDK `ByteRange`) alınır; gövde belleğe **alınmadan** `CopyToAsync` ile akıtılır; istemci koparsa istek iptal edilir ve depo akışı kapatılır.

### Virüs tarayıcı portu
```csharp
public interface IFileScanner { Task<ScanResult> ScanAsync(Stream content, CancellationToken ct); }   // ScanResult: Clean | Infected(signature) | Error
```
Varsayılan **`NoOpFileScanner`** (`Files:Scanner:Provider = none`; `scan_status = skipped`). ClamAV bağdaştırıcısı (clamd `INSTREAM`, `backend` ağında `clamav` servisi) **gelecekteki isteğe bağlı iştir**; bu kartta yalnız port + no-op + karantina durumu vardır. `Files:Scanner:OnInfected` = `reject` (varsayılan: bayt depoya **yazılmaz**, `422 file.infected`) | `quarantine` (nesne ve satır saklanır, `state = quarantined`, `scan_status = infected`, indirme `409 file.quarantined`, yalnız silinebilir; kotaya sayılır). `Files:Scanner:FailMode` = `open` (varsayılan, `Provider=none`) | `closed` (`Provider` verilmişken önerilir: tarayıcı `Error` → `503 file.scan_unavailable`). Tarama yalnız **ham baytlar** üzerindedir; sonuç metriği/günlüğü dosya adı içermez.

## Kota — M7 entegrasyonu (`maxStorageMb`)

- **Plan/istisna:** `limits.maxStorageMb` (`null` = sınırsız, `0` = hiç yükleme yok; ≥ 0, üst sınır 1 048 576) ve `overrides.maxStorageMb` (anahtar varlığı esas, `maxUsers` ile aynı: anahtar yok = plan, `null` = açıkça sınırsız). Örnek plan sayıları (`Platform:Plans`, ticari karar değildir): `internal` `null`, `starter` 1024, `business` 25600, `enterprise` 512000. Değişen M7 parçaları: `Shared.Contracts.Entitlements` (`LimitKeys.Storage = "storage"`, `EntitlementSnapshot`'a **isteğe bağlı son parametre** `int? MaxStorageMb = null` — mevcut çağrılar bozulmaz), `EffectiveEntitlements.Merge`, `PlanCatalogValidator` (≥ 0), `LimitGuard` (yeni `case LimitKeys.Storage`), `PlatformOptions`, abonelik/organizasyon DTO'ları, `overrides` doğrulaması (`errors["overrides.maxStorageMb"]`). `PUT …/subscription` `overLimit`'e `{ limit: "storage", module: "files", max, used }` ekler (bayt).
- **Ölçüm:** `FilesUsageReporter` (`Module = "files"`): `files.files` (adet: `ready|quarantined|missing`) ve `files.storage_bytes`. `files.records` **yoktur** (kayıt limiti değil). Böylece `usage_snapshots.metrics`, platform konsol grafiği ve **finans CSV'si** (M7) depolamayı otomatik taşır. `GET /subscription` `usage` içine `storageBytes`, `fileCount` ekler (kayıt sayılarıyla aynı ≤ 5 dk önbellekli görünüm, `asOf`); **zorlama** ise her zaman kesin ve önbelleksizdir.
- **Zorlama semantiği:** sert; kiracı başına kilit; `null` sınırda sayım **hiç yapılmaz** (sıfır ek sorgu). Silme kotayı anında düşürür. Plan düşürme mevcut dosyayı silmez: indirme/silme/liste açık, yeni yükleme `402` (M7 "veri silinmez" ilkesi). Salt okunur/askıda yükleme/silme/yeniden adlandırma `403 tenant.suspended` (komut), indirme çalışır (`accessLevel none` hariç).
- **Dosya başına sınır** kotadan ayrıdır (`file.too_large`, plana bağlı değil; yapılandırma). Files çekirdek modüldür (kapı modülü **değil**); ek yeteneği kapatmak için `maxStorageMb = 0` kullanılır.

## Yaşam döngüsü işleri (Worker)

Hepsi `BackgroundService`, `pg_try_advisory_lock` ile tek örnek, sahte saatle sürülebilir, kiracıları `ITenantContextSetter.BeginScope` ile tek tek işler (**yeni `IgnoreQueryFilters` yok**; M7 envanteri değişmez). Kiracı listesi: temizlikte `SELECT DISTINCT tenant_id FROM files.attachments WHERE …` (ham SQL, parametreli), uzlaştırmada `ITenantDirectory.ListAllAsync()`. **Ham SQL envanterine 3 yer eklenir** (M7 `TenantFilterBypassInventoryTests` ikinci envanteri): `FilesPurgeJob` (kiracı listeleme), `FilesReconciliationJob` (yalnız gerekiyorsa), `FilesObjectEraser`/`TenantDataEraser<FilesDbContext>` parametreli silme.

- **Temizlik (`FilesPurgeService`, `Files:Purge:PollMinutes` = 60):** `state = deleted` ve `deleted_at < now − SoftDeleteRetentionDays` satırlar için 200'lük parçalarla: nesneyi `DeleteAsync` (idempotent) → başarılıysa satırı fiziksel sil (audit izi `audit`'te kalır); nesne silme hatası satırı **bırakır** (sonraki tur). Aynı işte `file_access_log` saklama temizliği. Diğer kiracılara dokunmaz.
- **Uzlaştırma (`FilesReconciliationService`, `Files:Reconcile:PollHours` = 24; `migrator files-reconcile [--dry-run] [--tenant <id>]` aynı kodu koşar):** kiracı başına `ListAsync` ile nesneler ↔ satırlar: (1) **satır var, nesne yok** (veya boyut uyuşmuyor) → `state = missing` (indirme `410 file.content_missing`, kullanıcıya "dosya kullanılamıyor" + silebilir), `Error` günlüğü + `crm.files.reconcile.missing` sayacı; nesne sonradan geri gelirse (geri yükleme) `ready`'ye döner; (2) **nesne var, satır yok** ve `LastModified < now − OrphanGraceHours` (24; yükleme–commit penceresi korunur) → silinir; **güvenlik supabı:** silinecek yetim sayısı `MaxOrphanDeletePerRun` (1000) veya kiracının nesnelerinin `MaxOrphanDeleteFraction` (%5) oranını aşarsa **hiçbir şey silinmez**, `Error` günlüğü + sayaç (yanlış geri yükleme sonrası toplu silmeyi önler); (3) **bilinmeyen kiracı öneki** (dizinde yok) → **asla silinmez**, yalnız uyarı; (4) **kayıt-yok süpürmesi:** dosyası olan (tür, kayıt) çiftleri için `IAttachmentTarget.GetExistingAsync` (tür başına 500'lük toplu sorgu) — kayıt yoksa `record_missing_since` ayarlanır, geri gelirse (geri yükleme) temizlenir; `Files:Purge:RecordMissingGraceDays` (30) dolunca dosya yumuşak silinir (sistem kullanıcısıyla, `deleted_by_user_id = null`). `--dry-run` yalnız rapor yazar (kiracı başına sayılar; dosya adı yok).
- **Kiracı imhası (M7 uzantısı):** `FilesObjectEraser : ITenantDataEraser` (`Name = "files-objects"`, **`Order = 95`**: `workflows-conductor` 90'dan sonra, `module:files` 100'den önce). `BeginScope(tenantId)` → `DeletePrefixAsync` (döngü: listele + toplu sil, boşalana kadar; iterasyon üst sınırı) → **doğrulama:** önek altında `ListAsync` 0 nesne değilse istisna (adım `failed`, M7 yeniden deneme mantığı). Satırlar ve `file_access_log` `TenantDataEraser<FilesDbContext>` (sıra 100) ile otomatik gider (yansımayla kapsam testine girer); denetim `audit` adımında. `pending_deletion` kiracıda yüklemeler zaten `403 tenant.suspended` (`none`) olduğundan imha sırasında yeni nesne oluşmaz; uçuştaki bir yükleme için `migrator erase-deleted-tenants` (geri yükleme sonrası yeniden oynatma) adımı idempotenttir ve nesneleri yeniden siler. Rapor `report` içine `files.objects` sayısı girer (kişisel veri yok).
- **Yedek/geri yükleme (runbook):** bkz. "Runbook güncellemeleri".

## Denetim, olaylar, günlük

- **Denetim:** K14 varlık denetimi (`created`/`updated` (yeniden adlandırma)/`deleted`) — `FileAttachment` `IAuditLogged`. İndirme/önizleme `file_access_log`'a. Reddedilen yüklemeler (imza uyuşmazlığı, `infected`) `Warning` günlük + sayaç (`crm.files.upload.rejected{reason}`), **kişisel veri yok**.

- **Olaylar** (`Files.Contracts`, `IIntegrationEventOutbox.Enqueue` ile işlemle aynı `SaveChanges`'te; M8C'de tüketici yok, testler outbox satırını doğrular; **dosya adı taşımaz**):

  public sealed record FileAttached(Guid TenantId, Guid FileId, string RecordType, Guid RecordId, long SizeBytes, string ContentType, Guid? ActorUserId = null) : IntegrationEvent(TenantId, ActorUserId);
  public sealed record FileDeleted(Guid TenantId, Guid FileId, string RecordType, Guid RecordId, Guid? ActorUserId = null) : IntegrationEvent(TenantId, ActorUserId);

  `FileDeleted` kullanıcı silmesinde (yumuşak) yayınlanır; temizlik/süpürme yayınlamaz (süpürme kaynaklı silme `ActorUserId = null` ile yayınlar). `InProcessEventBus` kapısı (M7) bu olaylar için de geçerlidir.

## HTTP kontratı (`/files`; `recordType` ∈ `account|contact|lead|deal|activity|case|quote|order|campaign`)

Tüm uçlar Bearer ister. İzin kararı yukarıdaki eşleme + karar sırasıdır. Dosya kimliğiyle uçlarda yol `{id:guid}` kısıtlıdır.

**Dosya yanıtı (`FileDto`):**
```json
{ "id": "…", "recordType": "account", "recordId": "…", "name": "Sözleşme.pdf", "extension": "pdf", "contentType": "application/pdf",
  "sizeBytes": 184223, "sha256": "9f86d0…", "state": "ready", "uploadedByUserId": "…", "uploadedByName": "Ayşe Yılmaz",
  "uploadedAt": "2026-09-20T09:00:00Z", "updatedAt": "…", "canPreview": true }
```
`state` ∈ `ready|quarantined|missing` (`deleted` asla listelenmez). `uploadedByName` `IMemberLookup` ile **toplu** çözülür (çözülemezse yazılmaz). `canPreview` = önizlenebilir tür **ve** `ready`. `updatedAt` yalnız yeniden adlandırıldıysa.

### Liste
`GET /files?recordType*&recordId*&q&sort&page&pageSize` → sayfalı `FileDto`. Yazma değil **okuma** izni; `q` ad üzerinde `ILIKE` (joker kaçışlı). `sort` beyaz liste: `name`, `sizeBytes`, `extension`, `uploadedAt` (varsayılan `-uploadedAt`); her zaman `id` ile kararlı. Eksik/geçersiz `recordType`/`recordId` `400 validation`. İzin yok `403 forbidden`; kayıt yok `404 file.record_not_found`; kapı modülü kapalı `403 plan.module_disabled`.

### Yükleme
`POST /files?recordType*&recordId*` — `Content-Type: multipart/form-data`; bir veya daha çok **`file`** parçası (başka ad `400 file.upload_invalid`; `file` parçası yok/çok biçimsiz aynı kod; multipart değil `400 file.upload_invalid`). Parçanın `filename` (ve `filename*`) değeri **ham girdi**dir, temizlenir; parça `Content-Type` beyanı danışmandır. Yanıtlar:
- **201** `{ "items": [FileDto…], "failed": [] }` (tek dosyada ayrıca `Location: /api/v1/files/{id}`).
- **200** `{ "items": [FileDto…], "failed": [ { "fileName": "rapor.exe", "code": "file.type_not_allowed", "args": { "extension": "exe" } } ] }` (kısmi başarı).
- Hiçbiri başarılı değilse ilk hatanın ProblemDetails'i (aşağıdaki kodlar). Erken red (izin/varlık/plan/`tenant.suspended`) gövde okunmadan döner.

### Meta, indirme, yeniden adlandırma, silme
- `GET /files/{id}` → `FileDto` (okuma izni; izinsiz veya yok: `404 not_found`).
- `GET /files/{id}/content?disposition=attachment|inline` (varsayılan `attachment`) → dosya baytları (başlıklar/aralık: "Sunum başlıkları", "Aralıklı indirme"). `quarantined` `409 file.quarantined`; `missing` `410 file.content_missing`; depo erişilemez `503 file.storage_unavailable`; önizlenemeyen türde `inline` `400 validation`. Kayıt `file_access_log`'a yazılır. Rate limit `files-download`.
- `PATCH /files/{id}` `{ name* }` → **204** (yazma izni; ad temizlenir; **uzantı değişemez**: uzantısı farklıysa `400 file.extension_change_not_allowed`; ad çakışması denetlenmez — aynı kayıtta aynı ad olabilir). Yalnız `ready|quarantined|missing`.
- `DELETE /files/{id}` → **204** (yazma izni; yumuşak silme, kotadan anında düşer, `FileDeleted`; zaten silinmiş/yok `404 not_found`).

### Kullanım ve sınırlar
- `GET /files/usage` (`org.settings.manage`; canlı, önbelleksiz) → `{ "usedBytes": 3221225472, "fileCount": 214, "maxBytes": 26843545600, "quarantinedCount": 0, "missingCount": 0, "byRecordType": [ { "recordType": "account", "fileCount": 80, "sizeBytes": 1200000000 } ], "asOf": "…" }` (`maxBytes` yalnız sonlu limitte).
- `GET /files/limits` (herhangi bir kimliği doğrulanmış kullanıcı; kiracı-bağımsız yapılandırma) → `{ "maxFileBytes": 26214400, "maxFilesPerRequest": 10, "allowedExtensions": ["pdf","png",…], "previewableExtensions": ["pdf","png","jpg","jpeg","gif","webp"] }` (web istemci tarafı ön doğrulama; sunucu **her zaman** yetkilidir).
- **Değişen M7 uçları:** `GET /subscription` → `limits.maxStorageMb?` (yalnız sonlu), `usage.storageBytes`, `usage.fileCount`; `PUT /platform/organizations/{tenantId}/subscription` `overrides.maxStorageMb?`; `GET /platform/organizations/{tenantId}` etkin `limits.maxStorageMb?`; `GET /platform/plans` `limits.maxStorageMb?`.

## Hata kodları (metinler `SharedResource{,.en}.resx`'e; `field.file.*`)

| code | HTTP | Ne zaman |
|---|---|---|
| `validation` | 400 | `recordType`/`recordId`/`disposition`/`name`/sayfalama geçersiz (`errors`) |
| `file.upload_invalid` | 400 | multipart değil, `file` parçası yok, bilinmeyen parça adı, bozuk gövde |
| `file.too_many_files` | 400 | parça sayısı > `MaxFilesPerRequest` (`args.max`) |
| `file.empty` | 400 | 0 baytlık dosya |
| `file.name_invalid` | 400 | temizlemeden sonra ad boş |
| `file.extension_change_not_allowed` | 400 | yeniden adlandırmada uzantı değişti |
| `file.too_large` | **413** | dosya > `MaxFileMb` veya istek > `MaxRequestMb` (`args.maxBytes`) |
| `file.type_not_allowed` | **415** | uzantı allow-list'te değil / tehlikeli çift uzantı (`args.extension`) |
| `file.content_mismatch` | **422** | içerik imzası uzantı/beyan ailesiyle uyuşmuyor, makro/yürütülebilir içerik |
| `file.infected` | **422** | tarayıcı zararlı buldu (`OnInfected=reject`) |
| `file.quota_exceeded` | **402** | depolama kotası (`args.maxBytes`, `args.usedBytes`, `args.requestedBytes`) |
| `file.quarantined` | 409 | karantinadaki dosya indirilemez |
| `file.content_missing` | **410** | satır var, nesne yok (uzlaştırma `missing` işaretledi) |
| `file.scan_unavailable` | **503** | tarayıcı hatası ve `FailMode=closed` |
| `file.storage_unavailable` | **503** | depo erişilemez / şifreleme doğrulanamadı |
| `file.record_not_found` | 404 | hedef kayıt yok/silinmiş/başka kiracı (liste/yükleme) |
| `not_found` | 404 | dosya yok/başka kiracı **veya** kaydı okuma izni yok (sızıntı yok) |
| `forbidden` | 403 | kaydın yazma/okuma izni yok (liste, yükleme, ad değiştirme, silme) |
| `tenant.suspended` / `plan.module_disabled` | 403 | M7 (`args.reason` / `args.module`) |
| `general.rate_limit_exceeded` | 429 | `files-upload`/`files-download`/eşzamanlı yükleme sınırı |
